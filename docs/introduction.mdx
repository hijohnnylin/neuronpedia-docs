# Introduction

![Neuronpedia Logo](/img/intro.gif)

### What is Neuronpedia?

[Neuronpedia](https://neuronpedia.org) is an open source platform for interpretability research. It lets you explore, visualize, and steer the internals of AI models. It is both:

- **A public database** of data from inside models: features, activations, explanations, attribution graphs, attention heads, and more.
- **A set of free tools and APIs** to test ideas about how models work, with no setup and no GPU.

![The Neuronpedia home page.](/img/docs/home.png)

### What Can I Do on Neuronpedia?

| Tool | What it does |
| --- | --- |
| [**Sparse Autoencoders**](./sparse-autoencoders/overview) | Look at features from SAEs and transcoders. Search them and test them with your own text. |
| [**Steering**](./steering) | Change a model's output with features or your own vectors. |
| [**Circuit Tracing**](./circuit-tracing/overview) | Make attribution graphs that show the steps inside a model as it writes. |
| [**Attention Heads**](./attention-heads) | Explore 36,000+ attention heads in 37 models with HeadVis. |
| [**Jacobian Lens**](./jacobian-lens) | See the concepts that a model "holds in mind" at each token. |
| [**Natural Language Autoencoders**](./natural-language-autoencoders) | Translate a model's activations into plain English. |
| [**Assistant Axis**](./assistant-axis) | Watch a model drift from its assistant persona, and keep it there. |
| [**API & Data**](./api-and-data/api) | Use all of this from code, or download it. |

New to Neuronpedia? Start with [Key Concepts](./getting-started/key-concepts).

### Why Neuronpedia?

TL;DR - Researchers do research. We accelerate them by doing everything else: visualizations, tooling, sharing, scaling, and hosting.

When a research group releases new work (like SAEs, a new lens, or a new method), we put it on Neuronpedia so that anyone can use it right away. See [Research Releases](./research-releases/overview).

Neuronpedia is [open source](./open-source/self-hosting). The models run on [interp-engine](./open-source/interp-engine), our open source interpretability engine.
