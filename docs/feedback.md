# Feedback & Support

There is nothing we like more than fixing bugs and building the features that you ask for. Send us your most ambitious ideas. We will give you credit for them, if you want.

- **Email** - [johnny@neuronpedia.org](mailto:johnny@neuronpedia.org)
- **Slack** - Ask in [#neuronpedia on the Open Source Mechanistic Interpretability Slack](https://join.slack.com/t/opensourcemechanistic/shared_invite/zt-3z9o0hxjl-MDX9pbATO2qESOazNDLpdQ) for a fast reply.
- **GitHub** - [Open an issue](https://github.com/hijohnnylin/neuronpedia/issues) for bugs and feature requests.
- **Contact form** - [neuronpedia.org/contact](https://www.neuronpedia.org/contact)
- **Status** - Check if all services are up at [status.neuronpedia.org](https://status.neuronpedia.org).

We're excited to hear from you!
