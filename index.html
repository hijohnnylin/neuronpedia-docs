Introduction

What is Neuronpedia?​

Neuronpedia is an open source platform for interpretability research. It lets you explore, visualize, and steer the internals of AI models. It is both:

  • A public database of data from inside models: features, activations, explanations, attribution graphs, attention heads, and more.
  • A set of free tools and APIs to test ideas about how models work, with no setup and no GPU.

What Can I Do on Neuronpedia?​

ToolWhat it does
Sparse AutoencodersLook at features from SAEs and transcoders. Search them and test them with your own text.
SteeringChange a model's output with features or your own vectors.
Circuit TracingMake attribution graphs that show the steps inside a model as it writes.
Attention HeadsExplore 36,000+ attention heads in 37 models with HeadVis.
Jacobian LensSee the concepts that a model "holds in mind" at each token.
Natural Language AutoencodersTranslate a model's activations into plain English.
Assistant AxisWatch a model drift from its assistant persona, and keep it there.
API & DataUse all of this from code, or download it.

Why Neuronpedia?​

TL;DR - Researchers do research. We accelerate them by doing everything else: visualizations, tooling, sharing, scaling, and hosting.

When a research group releases new work (like SAEs, a new lens, or a new method), we put it on Neuronpedia so that anyone can use it right away. See Research Releases.

Neuronpedia is open source. The models run on interp-engine, our open source interpretability engine.
